# Minesweeper Game

A classic Minesweeper game built with vanilla JavaScript, HTML, and CSS. Play online since the Minesweeper Online is blocked on school devices.

## Features

- 🎮 Classic Minesweeper gameplay with customizable difficulty
- 🌐 Fully functional web-based version
- 📱 Responsive design that works on desktop and mobile
- 💾 Progressive Web App with offline support
- ⚡ Fast and lightweight with no dependencies

## How to Play

1. Click on cells to reveal them
2. Numbers show how many mines are adjacent to that cell
3. Right-click to flag cells you think contain mines
4. Reveal all non-mine cells to win!

## Getting Started

### Play Online
[Play here](https://lewis-minesweeper.vercel.app/)

### Run Locally

```bash
git clone https://github.com/Gzilla999/Minesweeper.git
cd Minesweeper
# Open index.html in your browser
```
## Offline Support

This project includes a service worker (sw.js) for offline functionality, allowing you to play even without an internet connection.
